# 深清手机端 · 兼容契约 v1

> 三方：**深清桌面（宿主）** ↔ **深清 AI 沟通插件（桥接服务）** ↔ **深清 Android 原生手机端**
>
> 手机端是 Kotlin + Jetpack Compose 原生应用，不加载网页/不执行桌面插件；兼容发生在 HTTP + JSON 协议与主题包层。版本规则：主版本必须相等，次版本只增不改。

## 0. 角色

- 宿主：Windows 深清，Python 3.13 + PySide6/QML，插件同进程加载（api_version 0.1）。
- AI 沟通插件：com.shenqing.aichat，在宿主内起局域网 HTTP 桥接，暴露空间/统计/会话/插件元数据/主题。
- 手机端：Android 原生。没有桥接时使用本机数据与主题；有桥接时读取桌面数据、插件 mobile 指标与主题包。

## 1. 传输

| 项 | 规定 |
| --- | --- |
| 基址 | http://host:port，默认 17777 |
| 前缀 | /shenqing/v1 |
| 编码 | UTF-8，application/json |
| 认证 | Authorization: Bearer <pairing-token>；GET /ping 例外 |
| CORS | Access-Control-Allow-Origin: *，允许 Authorization 与 OPTIONS |
| 超时 | 普通 8s，AI 60s |
| 未知字段 | 忽略 |
| 未知能力 | 隐藏入口，不调用 |

配对串：shenqing://pair?host=...&port=17777&token=...

## 2. 版本协商

GET /ping（无认证）：

    {"shenqing":true,"protocol":{"major":1,"minor":0},"app":"深清"}

major != 1 拒绝连接；minor 高时只使用本端已知能力。

## 3. 清单

GET /shenqing/v1/manifest：

    {
      "schema":"shenqing.bridge/v1",
      "protocol":{"major":1,"minor":0},
      "host":{"name":"深清","version":"0.18.0","platform":"windows"},
      "plugin":{"id":"com.shenqing.aichat","name":"AI 沟通","version":"1.0.0","api_version":"0.1"},
      "capabilities":["chat","history","spaces","stats","theme","plugins","themes"],
      "theme":{"modes":["solid","light","glass","ocean"],"defaultMode":"solid","tokenVersion":1},
      "endpoints":{"theme":"/shenqing/v1/theme","spaces":"/shenqing/v1/spaces","stats":"/shenqing/v1/stats","chat":"/shenqing/v1/chat","conversations":"/shenqing/v1/conversations","themes":"/shenqing/v1/themes"}
    }

能力全集（v1）：chat、chat.stream、history、spaces、stats、theme、plugins、session.control、themes。手机端不声明 session.control 时不能远程开始/结束桌面专注。

## 4. 主题

### 4.1 单一事实源

桌面 src/shenqing/qml/theme/AppTheme.qml（v0.18+）是唯一事实源。tools/build_theme_tokens.py 解析它并生成：

- theme/tokens.json（协议/文档/桌面插件共用）
- app/src/main/assets/theme_tokens.json（Android 运行时）

当前：79 个颜色 × 4 模式（solid/light/glass/ocean）+ heatLegend / appUsageColors 两个列表。

颜色格式为 Qt 的 #AARRGGBB（8 位时 alpha 在前）；6 位表示不透明。Android 端用 Color(Int) 解析。

### 4.2 主题接口

GET /shenqing/v1/theme?mode=solid：

    {
      "schema":"shenqing.theme/v1",
      "tokenVersion":1,
      "mode":"solid",
      "colors":{"bgTop":"#061C26","cardBorder":"#2BFFFFFF"},
      "lists":{"heatLegend":["#176B68","#1E9E95","#2ED3C6"]},
      "font":{"scale":1.0,"family":""}
    }

未知 mode 回退 solid；插件可返回颜色子集，但 tokenVersion 必须为 1；手机端网络失败时用本地 asset。

### 4.3 主题包（手机/桌面共用）

扩展名 .sqtheme，内容为 shenqing.theme-pack/v1 JSON。桌面用 6 键 palette（#RRGGBB）安装到 settings.custom_themes，theme_mode = custom:<id>；手机端可叠加完整 modes.solid.colors（79 键）到内置主题上。详见 docs/主题包规范.md。

GET /shenqing/v1/themes：

    {
      "schema":"shenqing.themes/v1",
      "themes":[
        {"id":"com.shenqing.theme.aurora","name":"极光","author":"深清示例","version":"1.0.0","builtIn":false,"description":"深色极光"}
      ]
    }

GET /shenqing/v1/themes/{id} 返回主题包 JSON：

    {
      "schema":"shenqing.theme-pack/v1",
      "id":"com.shenqing.theme.aurora",
      "name":"极光",
      "palette":{"bgTop":"#06121F","bgMid":"#0A1A2A","bgBottom":"#0B2233","accent":"#8B5CF6","cardBg":"#0D1A2B","textPrimary":"#F2F7FF"}
    }

插件应同时列出：

1. %APPDATA%\ShenQing\themes\*.sqtheme；
2. 插件目录 themes/*.sqtheme；
3. 宿主 settings.json 里已安装的 custom_themes（桌面 0.18+ 的主题页安装的）。

## 5. 空间与会话

GET /shenqing/v1/spaces 的 spaces / active 字段与 v1 前保持一致；tier 为 light/cover/deep/sleep；active.remainingSeconds 非负整数。

手机端只读镜像：没有 session.control 时，手机端不显示远程暂停/结束；本地计时不受影响。

## 6. 数据

GET /shenqing/v1/stats?range=7d：todayMinutes、weekMinutes、streakDays、sessionCount、last7Days（7 条、日期升序）、categories。手机桌面组件使用本机统计，不直接请求网络。

## 7. AI 对话

POST /shenqing/v1/chat：请求包含 conversationId、messages、stream=false；响应包含 ok、message.content、可选 reasoning/tokens/usage。
未配置 503 not_configured；上游失败 502 upstream；错误绝不回显 API Key。

## 8.1 桌面设置白名单（/settings）

GET /shenqing/v1/settings 返回手机端可读的桌面设置，**不含任何 token / API Key / 密码**：

    {
      "schema":"shenqing.settings/v1",
      "themeMode":"custom:aurora",
      "fontScale":1.0,
      "fontFamily":"",
      "navMode":"expanded",
      "language":"zh_CN",
      "storeCatalogUrl":"",
      "cloud":{"url":"https://store.example.com","email":"a@b.com","loggedIn":true,"lastAt":"","device":""},
      "customThemes":[{"id":"aurora","name":"极光","description":"","palette":{"bgTop":"#06121F"}}]
    }

手机端「从电脑读取配置」用它同步主题、字号和云同步地址；登录令牌不会通过桥接暴露。

## 8.2 账户同步（桌面 v0.20）

手机端与桌面共用商店服务端：

    POST /api/auth/login {email,password} -> {token}
    GET  /api/sync -> {revision, updated_at, payload, device_name}
    PUT  /api/sync {payload, revision, device} -> {revision} / 409 {revision}

手机端只合并 payload.settings 的 theme_mode / ui_font_scale / custom_themes：
不覆盖桌面 spaces / stats；上传前拉最新 revision，409 重拉合并；密码不落盘。

## 8. 插件与 mobile 元数据

GET /shenqing/v1/plugins 返回每个插件：

    {
      "id":"com.shenqing.tomatodo",
      "name":"番茄同步",
      "version":"1.0.0",
      "enabled":true,
      "mobile":{
        "summary":"番茄ToDo 数据互通",
        "metrics":[
          {"key":"today_sessions","label":"今日专注","value":"2","unit":"次"}
        ]
      }
    }

插件在 plugin.json 中声明 mobile 摘要/指标：

    "mobile": {
      "summary": "番茄ToDo 数据互通 · 深清专注历史",
      "metrics": [
        {"key":"today_sessions","label":"今日专注","source":"settings.history","aggregate":"today_count","unit":"次"}
      ]
    }

桥接插件读取 plugin_data/<id>/settings.json，支持 source=settings.<key> 与 aggregate=today_count/today_minutes/count。手机端只展示，不执行插件代码。

## 9. 错误体

    {"schema":"shenqing.error/v1","ok":false,"error":{"code":"unauthorized","message":"配对令牌无效"}}

错误码：unauthorized / bad_request / not_found / locked / not_configured / upstream / internal。

## 10. 兼容矩阵

| 场景 | 手机端行为 |
| --- | --- |
| 无桥接 | 本机空间/统计/主题，本地专注与组件正常 |
| major 不匹配 | 拒绝连接，提示协议版本 |
| 能力缺失 | 隐藏对应入口 |
| 主题失败 | 用本地 asset，不闪断 |
| AI 未配置 | 提示“桌面 AI 未配置”，不静默 |
| 插件版本高 | 只用已知字段 |

## 11. 一致性检查

手机端 Python 侧：cd 深清插件开发/com.shenqing.aichat && python -m unittest discover -s tests -v（当前 24 项通过，含 /themes、/settings、桌面自定义主题与 mobile 指标）。
协议 Node 检查器：node tools/conformance.mjs --base ... --token ...（检查 ping/manifest/theme/spaces/stats/chat/CORS/错误体）。
主题漂移：python tools/build_theme_tokens.py --check。

## 12. 实现状态（2026-11-14）

- 手机端：Android 原生，Kotlin + Compose；四档专注、深度锁机、桌面组件、主题包、桥接插件页。
- 插件：20+2 项 Python 测试通过；theme_tokens.json 与手机端 theme/tokens.json 逐字节一致。
- 桌面 v0.18 已支持 custom:<id> 自定义主题；主题包通过 6 键 palette 两端复用。
- 已知限制：远程开始/结束桌面专注未提供（宿主 API 0.1 无会话控制）；手机端 v1 不执行桌面插件，只读 mobile 元数据/指标；Android 非 Device Owner 的锁机无法绝对阻止强制停止/关机。
