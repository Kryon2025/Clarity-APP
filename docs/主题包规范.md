# 深清主题包规范（手机 / 桌面共用）

版本：shenqing.theme-pack/v1

## 1. 文件

- 扩展名 .sqtheme，内容是 **UTF-8 JSON 对象**；
- 手机端导入后保存在应用私有 filesDir/themes/<id>.sqtheme；
- 桌面端由 tools/install_theme_pack.py 读取，写入 %APPDATA%\ShenQing\settings.json 的 custom_themes；
- 桌面 0.18+ 的 AppTheme.qml 已支持 theme_mode = custom:<id> 与 customPalette，安装后即时生效。

## 2. 适配端（双端 / 单端）

主题包用 platforms 声明能在哪些端使用：

    "platforms": ["desktop", "mobile"]   // 双端
    "platforms": ["desktop"]             // 仅桌面
    "platforms": ["mobile"]              // 仅手机

- 桌面商店安装：只接受 platforms 含 desktop 的包；缺省按桌面兼容；
- 手机外观商店：platforms 含 mobile 才能应用；缺省按双端兼容；
- 手机本地导入桌面单端包会保留但显示「仅桌面」，不自动应用；
- 主题包不写 platforms 时视为旧包，手机端按双端兼容，桌面端按桌面处理。

## 3. 最小可用示例

    {
      "schema": "shenqing.theme-pack/v1",
      "id": "com.example.aurora",
      "name": "极光",
      "author": "你的名字",
      "version": "1.0.0",
      "description": "深色极光，紫青强调色",
      "palette": {
        "bgTop": "#06121F",
        "bgMid": "#0A1A2A",
        "bgBottom": "#0B2233",
        "accent": "#8B5CF6",
        "cardBg": "#0D1A2B",
        "textPrimary": "#F2F7FF"
      }
    }

## 4. 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| schema | 建议 | 固定 shenqing.theme-pack/v1 |
| id | 是 | 字母/数字开头，只含字母数字点下划线短横线，≤64 |
| name | 是 | 显示名 ≤40 |
| author / version / description | 否 | 展示信息 |
| platforms | 否 | 适配端：["desktop"] 单端桌面、["mobile"] 单端手机、["desktop","mobile"] 双端；缺省按双端兼容 |
| palette | 是（桌面） | 6 个 #RRGGBB：bgTop / bgMid / bgBottom / accent / cardBg / textPrimary |
| modes | 否 | 完整 79 色令牌（见下）；手机可只用某个模式 |
| base | 否 | 手机叠加模式，默认 solid |
| desktop | 否 | 给桌面开发者的提示/资源说明 |

### 桌面 palette（6 键）

桌面 AppTheme 用这 6 个键决定底色、强调色、卡片和正文，并根据底色亮度推导次要文字/描边/按钮色，保证可读性。颜色必须是 #RRGGBB（不接受 8 位 alpha）。

### 手机 modes（79 键，可选）

    "modes": {
      "solid": {
        "colors": {
          "bgTop": "#06121F",
          "bgMid": "#0A1A2A",
          "bgBottom": "#0B2233",
          "accent": "#8B5CF6",
          "cardBg": "#0D1A2B",
          "textPrimary": "#F2F7FF"
        }
      }
    }

手机端把 modes.solid.colors 叠加到内置 solid 上；未提供的键沿用内置值。完整键表由 theme/tokens.json 给出（79 色 + heatLegend / appUsageColors 两个列表），由 python tools/build_theme_tokens.py 从桌面 AppTheme.qml 生成。

## 5. 安装

### 手机

设置 / 插件页「导入 .sqtheme」→ 选择文件 → 立即应用；也可由桌面桥接 /themes 下载后应用。

### 桌面（0.18+）

先退出深清（避免运行中的设置覆盖文件）：

    python tools/install_theme_pack.py themes/aurora.sqtheme

脚本会：

1. 校验 id / palette；
2. 备份 settings.json；
3. 合并 custom_themes；
4. 设置 theme_mode = custom:<id>（可用 --no-activate 只安装不切换）。

重启深清后，主题页会出现这个自定义主题。

## 6. 兼容规则

- 桌面端使用 6 键 palette；手机端优先读 palette，再读 modes.solid.colors，最后用内置值补齐；
- 不建议让手机和桌面使用完全不同的底色：共享 palette 才能保证两端看起来是同一套主题；
- 8 位 #AARRGGBB 仅在完整 modes 令牌中允许（Qt 语义），桌面 palette 必须是 6 位；
- 主题包不包含可执行代码；桌面不会因为安装主题执行任意 QML/Python；
- id 必须唯一；同名 id 后安装会覆盖。

## 7. 校验

    python tools/install_theme_pack.py path/to/theme.sqtheme --check

会打印解析后的 palette 并校验必填字段；退出码 0 表示可用于桌面安装，手机端也会接受同样的文件。
