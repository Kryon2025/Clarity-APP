## 1. 交付形态

- Kotlin + Jetpack Compose Android 应用，applicationId com.shenqing.mobile，minSdk 26 / targetSdk 35；
- Debug APK：app/build/outputs/apk/debug/app-debug.apk（约 16 MB）；

## 3. 功能验收（代码/构建级）

- 四档空间与时长选择、浅清暂停/结束、覆清/深清锁定、连点 10 次出口；
- FocusService 前台通知、精确闹钟、开机恢复、倒计时结束自动记入统计；
- 无障碍服务监听前台应用：覆盖层拦截、桌面/设置/第三方应用切回专注；
- 桌面组件：今日次数、近 7 天次数、快速专注按钮；启动/结束/换主题自动刷新；
- 主题：内置 4 套 + .sqtheme 导入；桌面已安装 custom themes 可由 /themes 下载；
- 插件页：桥接状态、桌面插件卡片、mobile 指标、主题包列表；
- 账户同步：设置页直接登录桌面 v0.20 商店服务端，拉取/推送主题与字号；从桥接读取桌面设置白名单；
- 清番：底部页签 + PomodoroService + 暂停/跳过/退出 + Live Updates 通知；
- 版本：1.1.0 / versionCode 2；应用内下载更新并打开系统安装器；
- 设置页：顶部账户卡 / 个人资料 / 外观商店 / 插件商店 / 检查更新 / 关于，均为独立页面；
- 商店：外观主题从桌面 catalog 拉取 palette 与 platforms，双端/单端徽标与 mobile 应用门禁；插件商店展示 mobile 指标；
- 更新：预览/正式双渠道 + 应用内下载安装；
- 视觉：VendorUi 自适应玻璃卡片（OPPO 流光彩边）；
- OPPO 超禅：检测 OPPO 家族/禅定空间，优先调用超禅，时长映射与失败回退；
- 设置：无障碍/通知/电池/Device Owner 状态、桌面连接、添加组件、清除数据。
