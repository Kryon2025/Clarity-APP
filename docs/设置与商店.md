# 设置页、外观商店与插件商店

## 1. 设置页结构

- 顶部账户卡：未登录 → 登录；已登录 → 昵称 / 邮箱 / 个人资料；
- 菜单：外观商店、插件商店、账户与同步、检查更新、关于；
- 下方保留：主题网格、字号、桌面连接、锁机权限、OPPO 超禅、组件、清除数据。

### 个人资料

- 本机昵称保存在手机设置（profileName），不写云端；
- 邮箱来自商店账号，只读；
- 头像使用昵称首字，不依赖上传头像服务。

## 2. 外观商店

数据源：桌面商店目录

    https://raw.githubusercontent.com/Kryon2025/Clarity/store/catalog.json

- 只取 kind=theme；
- 每个条目带 6 键 palette；应用时调用 ThemeRepository.importPaletteTheme 写入本地 .sqtheme，再 apply；
- 同时展示内置主题和已导入的本地主题包；
- 网络失败时保留本地主题，不影响使用；
- 应用后自动刷新 Compose 主题、桌面组件颜色。

## 3. 插件商店

- 数据源同上，取 kind=plugin；
- 手机端不执行桌面 Python/QML 插件；
- 若桥接已连接，会显示桌面已安装插件的 mobile 摘要/指标；
- 安装仍应在电脑端深清商店完成；手机端只负责展示和读取 mobile 数据；
- 网络失败时展示 AI 沟通 / 番茄同步 / 暮语三个内置说明卡。

## 4. 检查更新

- GitHub API：Kryon2025/Clarity-APP releases/latest；
- 比较 tag_name 与当前 versionName；
- 有 Release 时可打开下载页；无 Release 时提示源码已同步 main。

## 5. 限制

- 商店目录是桌面商店的公共目录，不是手机专属商店；
- 外观商店目前不下载 screenshots，预览使用 palette 色块；
- 插件商店不能把桌面插件安装到手机，也不执行插件 UI；
- 需要网络与 INTERNET 权限；GitHub API 有限流。
