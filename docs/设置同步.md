# 电脑端设置 → 手机端同步（v0.20）

## 1. 两条同步通道

| 通道 | 用途 | 是否必须登录 |
| --- | --- | --- |
| 局域网桥接 /shenqing/v1/settings | 读取同一台电脑的主题 / 字号 / 云同步地址 / 邮箱 | 否（桥接 Bearer 令牌） |
| 商店服务端 /api/auth/login + /api/sync | 跨电脑账号同步 | 是 |

## 2. 桥接设置白名单

桌面 → AI 沟通插件 → 手机：

    GET /shenqing/v1/settings

返回：

    {
      "schema":"shenqing.settings/v1",
      "themeMode":"custom:aurora",
      "fontScale":1.0,
      "fontFamily":"",
      "navMode":"expanded",
      "language":"zh_CN",
      "storeCatalogUrl":"",
      "cloud":{"url":"https://store.example.com","email":"a@b.com","loggedIn":true,"lastAt":"","device":""},
      "customThemes":[{"id":"aurora","name":"极光","description":"","palette":{}}]
    }

不返回：pin、ai_api_key、cloud_sync_token、web_admin_token、本机路径。

手机「设置 → 账户同步 → 从电脑读取配置」会：

1. 填入云同步 URL / 邮箱；
2. 安装 customThemes 的 palette；
3. 应用 themeMode 与 fontScale。

## 3. 云同步快照

桌面 v0.20 payload 结构（白名单）：

    {
      "version": "...",
      "exported_at": "...",
      "settings": {
        "theme_mode": "custom:aurora",
        "custom_themes": {"aurora": {"name":"极光","palette":{}}},
        "ui_font_scale": 1.0
      },
      "spaces": {},
      "stats": {}
    }

手机端只合并 settings 的三个键：

- theme_mode
- ui_font_scale
- custom_themes

并保留远端 spaces / stats / 其他 settings 原样。这样手机不会把电脑的空间/统计覆盖成手机数据。

## 4. 冲突与备份

- 上传前 GET /api/sync 取最新 revision；
- PUT 收到 409 时重新拉取、合并，再 PUT 一次；
- 服务端有 revision 乐观锁；桌面拉取前有本地备份；
- 手机只保存 token / email / url / revision / lastAt，不保存密码。

## 5. 服务端配置

手机与桌面使用同一个商店服务端。服务端需要：

- POST /api/auth/login 可用（邮箱密码或验证码登录）；
- GET/PUT /api/sync 可用；
- 生产环境用 HTTPS；
- 自建服务端见 深清/docs/store-server-deploy.md。

手机端填写的地址示例：

    https://store.example.com
    http://192.168.1.10:8000

## 6. 已知限制

- 手机端只同步设置，不参与桌面空间/统计的双向合并；
- 服务端是单快照；桌面与手机同时上传仍按 revision 冲突处理，后上传者会覆盖 settings 的对应键；
- 未实现手机注册/验证码 UI，先在桌面或网页注册账号；
- 云端不保存明文密码、AI Key、桥接令牌。
